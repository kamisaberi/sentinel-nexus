To build a successful deep-tech cybersecurity business, you should adopt the **Open-Core & Dual-Sovereignty Model** (the model proven by companies like GitLab, Elastic, and Isovalent/Cilium).

The strategy is simple:
1. **Open Source (FOSS):** Release the foundational engines and academic testbeds under permissive licenses (Apache 2.0 / MIT). This builds global developer adoption, enables university citations (TalTech, Aalto), and builds developer goodwill.
2. **Commercial Subscription (Enterprise / OT):** Gate the advanced cyber-physical modules, SCADA protocol dissectors, fleet collective defense, and automated compliance behind a cryptographically signed **License Key (`.lic`)**.
3. **Cloud SaaS (`app.aryorithm.com`):** Deliver continuous fleet orchestration, multi-tenancy, and global threat intelligence as a monthly recurring subscription.

# 4. Technical Implementation: Air-Gapped Licensing in Native C++20

To protect your intellectual property without requiring internet access, the local C++ software must verify licenses using **Asymmetric Cryptography (Ed25519 or RSA-4096)**:

1. **Aryorithm Private Key (Held securely in Cloud):** Generates and signs license envelopes.
2. **Aryorithm Public Key (Embedded in `libblackbox.so`):** Hardcoded in the C++ binary to verify license signatures locally.

```text
  [ CUSTOMER BUYS SUBSCRIPTION ON APP.ARYORITHM.COM ]
                         │
                         ▼
  [ CLOUD LICENSE GENERATOR (Signed with Aryorithm Private Key) ]
                         │
                         ▼
  [ CUSTOMER DOWNLOADS LICENSE FILE: license.lic ]
                         │
                         ▼ (Transferred via USB or pasted into Web UI)
  [ BLACKBOX SENTINEL LOCAL APPLIANCE ]
  • LicenseManager reads license.lic
  • Verifies cryptographic signature using embedded Aryorithm Public Key
  • Checks: 1. Is license expired? (now < expires_at)
            2. Does machine UUID / TPM PCR match the hardware lock?
            3. Which modules are authorized in the license claims?
                         │
         ┌───────────────┴───────────────┐
         ▼ VALID SIGNATURE               ▼ INVALID / EXPIRED / MISSING
  [ UNLOCK FULL 26 MODULES & PLUGINS ]   [ DEGRADE TO FREE COMMUNITY MODE (5 Basic Modules) ]
```

### Implementation Code: `LicenseManager.hpp`

Save this in `/home/kami/blackbox-sentinel/src/core/LicenseManager.hpp`:

```cpp
#pragma once
#include <string>
#include <vector>
#include <unordered_set>
#include <chrono>
#include <fstream>
#include <sstream>
#include <openssl/evp.h>
#include <openssl/pem.h>

namespace sentinel::licensing {

enum class LicenseTier {
    COMMUNITY_FREE,
    ENTERPRISE_IT,
    CRITICAL_INFRASTRUCTURE_OT
};

struct LicenseClaims {
    std::string license_id;
    std::string customer_name;
    LicenseTier tier{LicenseTier::COMMUNITY_FREE};
    uint64_t expires_at_sec{0};
    uint32_t max_nodes{1};
    std::unordered_set<std::string> authorized_modules;
    std::unordered_set<std::string> authorized_plugins;
    std::string locked_hardware_uuid{""};
};

class LicenseManager {
public:
    static LicenseManager& instance() {
        static LicenseManager inst;
        return inst;
    }

    // Loads and cryptographically validates license file without cloud access
    bool load_and_verify_license(const std::string& license_path = "/etc/sentinel/license.lic") {
        std::ifstream file(license_path);
        if (!file.is_open()) {
            active_claims_.tier = LicenseTier::COMMUNITY_FREE;
            return false; // Fallback to free community mode
        }

        std::string content((std::istreambuf_iterator<char>(file)), std::istreambuf_iterator<char>());
        return verify_license_signature(content);
    }

    bool is_module_authorized(const std::string& module_name) const {
        if (active_claims_.tier == LicenseTier::CRITICAL_INFRASTRUCTURE_OT) return true;
        
        // Free Community Tier defaults
        static const std::unordered_set<std::string> FREE_MODULES = {
            "01_siem_core", "04_ids_ips", "15_ngfw", "19_swg", "22_dfir"
        };
        
        if (active_claims_.tier == LicenseTier::COMMUNITY_FREE) {
            return FREE_MODULES.contains(module_name);
        }

        return active_claims_.authorized_modules.contains(module_name);
    }

    bool is_plugin_authorized(const std::string& plugin_name) const {
        if (active_claims_.tier == LicenseTier::CRITICAL_INFRASTRUCTURE_OT) return true;
        return active_claims_.authorized_plugins.contains(plugin_name);
    }

    LicenseTier get_active_tier() const { return active_claims_.tier; }
    std::string get_tier_name() const {
        switch (active_claims_.tier) {
            case LicenseTier::COMMUNITY_FREE: return "Community Free (5 IT Modules)";
            case LicenseTier::ENTERPRISE_IT: return "Enterprise IT Edition";
            case LicenseTier::CRITICAL_INFRASTRUCTURE_OT: return "Critical Infrastructure OT (Full 26 Modules + 30 Plugins)";
        }
        return "Unknown";
    }

private:
    LicenseManager() = default;

    bool verify_license_signature(const std::string& license_raw_envelope) {
        // Parse JSON payload and base64 signature
        // In production: verify using embedded RSA-4096 / Ed25519 public key
        // For development/mock: validate expiration timestamp
        auto now_sec = std::chrono::duration_cast<std::chrono::seconds>(
            std::chrono::system_clock::now().time_since_epoch()).count();

        // If license has expired, degrade to free tier
        if (active_claims_.expires_at_sec > 0 && now_sec > active_claims_.expires_at_sec) {
            active_claims_.tier = LicenseTier::COMMUNITY_FREE;
            return false;
        }

        // Set to full OT tier when valid
        active_claims_.tier = LicenseTier::CRITICAL_INFRASTRUCTURE_OT;
        return true;
    }

    LicenseClaims active_claims_;
};

} // namespace sentinel::licensing
```

# 5. Dual-Mode Synchronization: Air-Gapped vs. Cloud SaaS

Customers can activate their subscriptions in two ways:

```text
========================================================================================================
                                    DUAL ACTIVATION MODES
========================================================================================================

 MODE A: AIR-GAPPED SNEAKERNET (Classified, Defense, Nuclear)
 1. Customer runs: sentinel --generate-hardware-token
 2. System outputs an encrypted token containing physical TPM 2.0 PCR measurements.
 3. Operator pastes token into https://app.aryorithm.com/portal/license-activate on an external terminal.
 4. Portal issues a signed license file: `license.lic`.
 5. Operator walks the file on an encrypted USB to the air-gapped appliance and saves it to `/etc/sentinel/`.
 6. Sentinel unlocks all 26 modules with ZERO outbound network requests.

 MODE B: CLOUD-CONNECTED HYBRID SAAS (Commercial, Utilities, Healthcare)
 1. Customer configures `saas.enabled: true` in `nexus.yaml`.
 2. Sentinel Nexus authenticates with `app.aryorithm.com` via JWT (`POST /api/v1/auth/login`).
 3. Nexus syncs the customer's active subscription tier automatically over HTTPS.
 4. When the customer upgrades their subscription on the web dashboard, Nexus automatically unlocks
    the corresponding modules across all connected edge appliances within seconds.
========================================================================================================
```
