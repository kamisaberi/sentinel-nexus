## 5. Technical Implementation: How Gating is Enforced

The licensing model is enforced through two technical mechanisms:

```text
========================================================================================================
                                  ENTITLEMENT ENFORCEMENT ENGINES
========================================================================================================

 1. ON-PREMISE AIR-GAPPED GATING (libblackbox.so & sentinel daemon)
    • License File: /etc/sentinel/license.lic (Signed JSON envelope)
    • Cryptography: Verified locally via Aryorithm's embedded Ed25519 Public Key.
    • Checks:
      - Valid signature? If NO ──> Degrade to Community Free (5 basic IT modules).
      - Expired? (now > expires_at) ──> Degrade to Community Free.
      - Hardware lock match? (Locked to physical TPM 2.0 PCR_0 or DMI UUID).
      - Module check: LicenseManager::is_module_authorized("18_cps_sec").

 2. CLOUD SAAS ENTITLEMENT GATING (FastAPI at app.aryorithm.com)
    • JWT Access Token claims: `{"sub": "...", "tenant_id": "...", "tier": "ENTERPRISE_OT"}`
    • Middleware: `Depends(require_scope("scada:analytics"))` or `require_tier("SOVEREIGN")`
    • If tenant attempts to access un-subscribed API routes (e.g., /compliance/export or /ai/compiler)
      ──> Returns HTTP 403 Forbidden ("Upgrade to Enterprise Tier to unlock this service").
========================================================================================================
```
